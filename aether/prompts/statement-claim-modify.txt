# Role
You are an expert in refining market claims based on empirical evidence. Your task is to modify a rejected claim according to statistical findings and modification suggestions provided by data analysis.

# Task
Given a rejected claim and its rationale containing modification suggestions, produce a revised claim that incorporates the empirical evidence while maintaining atomicity, verifiability, and specificity.

# Input Information

You will receive:

1. **Original Claim**:
   - claim: Original claim statement
   - condition: Original mathematical condition
   - data_columns: Required data columns
   - verification_plan: Original verification strategy

2. **Rationale**:
   - content: Statistical evidence and modification suggestions (may include verification plan evaluation)

# Modification Principles

## 1. Faithful to Evidence
- Incorporate ALL statistical findings from rationale
- Apply suggested modifications (direction reversal, threshold adjustment, metric change)
- Preserve valid aspects that were confirmed by data

## 2. Maintain Claim Structure
- Keep atomicity: single testable proposition
- Preserve verifiability: concrete condition expression
- Update data_columns if metric/columns changed
- Update verification_plan if rationale suggests verification strategy changes

## 3. Precision
- Use exact terminology from rationale
- Update condition expression to match new claim

## 4. Minimal Changes
- Only modify what rationale indicates needs change
- Keep unchanged aspects of original claim intact
- Do not add new claims or combine multiple claims

# Output Requirements

You must output a modified Claim with four fields:

1. **claim** (str): Revised natural language description
   - Incorporates modification suggestions from rationale
   - Maintains atomicity and specificity
   - 1-2 sentences maximum

2. **condition** (str): Updated mathematical/statistical expression
   - Reflects changes in claim (direction, threshold, metric)
   - Uses same format as original: "function(COLUMN, params) operator threshold"
   - Must be verifiable with provided data_columns

3. **data_columns** (list[str]): List of required columns
   - Update if rationale suggests different columns/metrics
   - Keep same if only direction/threshold changed

4. **verification_plan** (str): Updated verification strategy
   - If rationale suggests verification plan changes, update accordingly
   - If rationale indicates plan was appropriate, keep it with minor adjustments if needed
   - If rationale suggests plan improvements, incorporate those suggestions
   - If no verification plan feedback in rationale, keep original plan or adapt to match modified claim

# Important Guidelines

IMPORTANT: Read rationale content carefully. Look for explicit modification suggestions for both the claim and verification_plan.
IMPORTANT: If rationale suggests removing part of claim, delete that part from claim and condition.
IMPORTANT: If rationale suggests direction reversal, update BOTH claim and condition accordingly.
IMPORTANT: If rationale evaluates verification_plan, update it based on the feedback (e.g., change test direction, add/remove tests, adjust parameters).
IMPORTANT: Preserve market regime/context from original claim if present (e.g., "In trending markets").
IMPORTANT: Ensure modified condition expression matches the revised claim exactly.
IMPORTANT: Ensure verification_plan aligns with the modified claim (e.g., if claim direction changed, update test direction in plan).
IMPORTANT: Do not invent new claims or add information not suggested in rationale.

<input>

Calculate streak lengths of positive skewness periods and perform permutation test (1000 shuffles) to compare observed streak lengths against random baseline. Test relationship between positive skewness and actual gap-up behavior using correlation analysis.</verification_plan>
</original_claim>

<rationale>
<content>Analyzed rolling 20-period skewness across 39,365 periods, finding mean skewness of -0.028 (not positive) with only 47.5% positive periods versus 52.5% negative. One-sample t-test confirmed mean significantly differs from zero in the NEGATIVE direction (t=-6.91, p<0.001, Cohen's d=0.35). While permutation tests showed streak persistence is statistically significant (p<0.001), the directional bias contradicts the claim. Recommend modifying claim to "Opening prices exhibit sustained NEGATIVE skewness streaks indicating gap-down behavior" to match empirical evidence. The verification_plan was appropriate and effectively revealed the directional issue; suggest updating it to test for negative skewness instead of positive.</content>
</rationale>
</input>

<condition>streak_length(skew(OPEN, window=20) < 0) >= 3</condition>
<data_columns>['OPEN']</data_columns>
<verification_plan>Calculate 20-period rolling skewness of opening prices. Perform one-sample t-test against zero with alternative='less'. Calculate streak lengths of negative skewness periods and perform permutation test (1000 shuffles) to compare observed streak lengths against random baseline. Test relationship between negative skewness and actual gap-down behavior using correlation analysis.</verification_plan>
</output>

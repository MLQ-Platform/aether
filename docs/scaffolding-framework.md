## Augmentation Phase - Thesis 반박 및 보완 {#augmentation-phase}

### **1단계: 반박 논거 생성 (Counterargument Generation)**

**평가 기준 정의**
- 기술적 실현 가능성 (Technical Feasibility)
- 방법론적 엄격성 (Methodological Rigor)
- 이론적 타당성 (Theoretical Validity)
- 실용적 적용 가능성 (Practical Applicability)
- 일반화 가능성 (Generalizability)

**각 기준별 약점 식별**
- Thesis를 각 평가 기준으로 분석
- 해당 기준에서 취약한 부분 파악
- 잠재적 실패 지점 식별
- 과도한 가정이나 단순화 발견

**반박 유형 분류**
- 기술적 한계: 방법론이 실현 불가능하거나 제약이 큼
- 이론적 결함: 논리적 비약이나 이론적 오류
- 증거 부족: 주장을 뒷받침할 데이터/문헌 없음
- 외부 요인: 고려하지 않은 변수나 조건
- 대안 설명: 다른 해석이 더 타당함

**문헌 기반 반박 수집**
- Peer-reviewed literature에서 관련 연구 검색
- Thesis와 모순되는 발견 식별
- 실패한 유사 시도 사례 조사
- 제한 조건을 명시한 연구 찾기

**반박 논거 구체화**
- 각 약점에 대한 구체적 반박 작성
- 반박의 근거(문헌, 데이터) 명시
- 반박의 심각도 평가 (치명적/중요/경미)
- 반박이 적용되는 범위 명확화

---

### **2단계: 반박 우선순위 결정 (Prioritization)**

**심각도 평가**
- 치명적: Thesis 전체를 무효화할 수 있음
- 중요: 주요 결론에 영향을 줌
- 경미: 세부 사항에만 영향

**영향 범위 분석**
- Thesis의 어느 부분에 영향을 미치는가
- 핵심 주장에 직접 영향 vs 주변 주장에만 영향
- 여러 부분에 걸친 영향 vs 국소적 영향

**보완 가능성 평가**
- 쉽게 보완 가능 (추가 설명만으로)
- 보통 (방법론 일부 수정 필요)
- 어려움 (근본적 재설계 필요)

**최종 우선순위 선정**
- 심각도 높음 + 보완 가능 → 최우선
- 심각도 높음 + 보완 어려움 → Thesis 재검토 필요
- 심각도 낮음 → 선택적 보완

---

### **3단계: 보완 전략 수립 (Augmentation Strategy)**

**각 반박에 대한 대응 방식 결정**
- 인정 후 제약 조건 명시
- 추가 방법론으로 해결
- 대안적 해석 제시
- 범위 축소로 회피
- 향후 연구 과제로 연기

**보완 방법 설계**
- 추가 조건: 어떤 조건 하에서 성립하는지 명시
- 추가 방법: 약점을 보완하는 기술/방법 제시
- 추가 증거: 반박을 무력화하는 증거 제시
- 범위 한정: 적용 범위를 명확히 제한
- 단계적 접근: 현재는 일부만, 향후 확장

**통합 계획 수립**
- 보완 내용을 Thesis의 어디에 삽입할지 결정
- 원래 흐름과의 조화 고려
- 보완으로 인한 길이 증가 관리
- 핵심 메시지가 희석되지 않도록 주의

---

### **4단계: Thesis 보완 작성 (Augmentation Writing)**

**원본 Thesis 구조 분석**
- 서론/본론/결론 구조 파악
- 각 문단의 역할 식별
- 핵심 주장이 등장하는 위치 확인

**보완 내용 삽입**
- 관련 반박이 제기될 지점 바로 다음에 삽입
- "To address..." / "However..." 등으로 자연스럽게 연결
- 보완 내용이 독립된 문단 또는 문장으로 추가
- 원래 문장은 최대한 유지

**보완 표현 작성 기법**
- 인정형: "While [반박] is valid, we address this by [보완]"
- 해결형: "To overcome [반박], we employ [보완]"
- 제한형: "This approach applies to [제한된 범위], where [조건]"
- 단계형: "In this study, we focus on [일부], with [나머지] for future work"

**원본 텍스트와의 조화**
- 문체와 톤 유지
- 전문 용어 일관성 확보
- 논리적 흐름 자연스럽게 연결
- 길이와 복잡도 균형 유지

---

### **5단계: 일관성 검증 (Consistency Check)**

**내적 일관성 검사**
- 보완 내용이 원래 주장과 모순되지 않는지
- 새로 추가된 조건들이 서로 충돌하지 않는지
- 보완 후에도 결론이 여전히 타당한지

**완전성 검사**
- 모든 주요 반박이 다뤄졌는지
- 새로운 약점이 생기지 않았는지
- 보완이 충분히 구체적인지

**명확성 검사**
- 보완 내용이 모호하지 않은지
- 제한 조건이 명확히 표현되었는지
- 독자가 오해할 여지가 없는지

**범위 검사**
- 보완으로 인해 주장이 너무 약화되지 않았는지
- 제한 조건이 너무 많아 적용 범위가 극히 좁아지지 않았는지
- 여전히 의미 있는 기여를 하는지

---

### **6단계: 문헌 인용 보강 (Citation Enhancement)**

**보완 내용에 대한 근거 추가**
- 각 보완 방법에 대한 문헌 인용
- 유사 접근법의 성공 사례 인용
- 제한 조건의 타당성을 뒷받침하는 연구 인용

**인용 형식 통일**
- 저자명, 연도, 저널 등 일관된 형식
- 본문 내 인용과 참고문헌 목록 매칭
- 인용의 정확성 확인

**인용의 적절성 검증**
- 인용한 논문이 실제로 주장을 뒷받침하는지
- 맥락이 왜곡되지 않았는지
- 최신 연구로 업데이트 가능한지

---

### **7단계: 최종 검토 (Final Review)**

**원본과 보완본 비교**
- 핵심 메시지가 보존되었는지
- 불필요하게 방어적이지 않은지
- 자신감 있으면서도 겸손한 톤 유지

**독립적 검증 가능성**
- 제3자가 읽었을 때 설득력 있는지
- 명백한 허점이 남아있지 않은지
- 추가 질문이 생길 만한 부분 파악

**다음 단계 준비**
- 보완된 Thesis가 그래프 분해 준비 완료 상태인지
- 복잡도가 적절한지 (너무 길거나 복잡하지 않은지)
- 핵심 주장들이 명확히 식별 가능한지

**버전 관리**
- 원본 Thesis 보존
- 보완 Thesis를 새 버전으로 저장
- 변경 사항 로그 작성
- Iteration 0로 표시 (Graph Iteration 전 단계)

---

### **보완 품질 기준**

**효과적인 보완의 특징**
- 원래 접근법의 핵심은 유지함
- 주요 반박에 대한 실질적 대응을 제시함
- 보완 방법이 실현 가능하고 구체적임
- 문헌으로 뒷받침됨
- 논리적 흐름이 자연스러움

**피해야 할 함정**
- 모든 반박을 다루려다 너무 길어짐
- 과도한 제한 조건으로 주장이 무의미해짐
- 근거 없는 낙관적 주장으로 반박 회피
- 원래 메시지가 희석됨
- 방어적 태도로 설득력 저하

---

## Thesis → Logic Graph 분해 {#thesis-to-graph}

### **1단계: 전처리 (Preprocessing)**

**문단 분리**
- 보완된 thesis를 의미 단위 문단으로 나누기
- 각 문단의 주제/역할 식별 (문제정의, 방법론, 결과 등)
- 문단 간 순서와 의존성 파악

**문장 단위 분할**
- 각 문단을 개별 문장으로 분리
- 복문을 단문으로 분해 (접속사 기준)
- 종속절을 독립적 명제로 변환

**의미 단위 추출**
- 각 문장에서 핵심 주장/사실 식별
- 하나의 문장에 여러 주장이 있으면 분리
- 암묵적 전제 명시화

---

### **2단계: 정점 생성 (Vertex Creation)**

**원자적 명제 추출**
- 더 이상 분해하면 의미가 흐려지는 최소 단위 식별
- 각 명제가 단독으로 이해 가능한지 확인
- 참/거짓 판단이 가능한 형태로 표현

**정점 타입 분류**
- Key Concept: 핵심 주장/결론
- Supporting Evidence: 실험 데이터, 문헌 인용
- Method: 기술, 방법론, 도구
- Intermediate Conclusion: 중간 결론
- Problem/Context: 배경, 문제 정의
- Validation: 검증 메커니즘

**정점 텍스트 정규화**
- 모호한 표현 제거 (it, this, that 등을 구체적 명사로 대체)
- 측정 가능한 용어로 변환
- 명확한 주어-동사-목적어 구조로 재작성

**정점 메타데이터 설정**
- 고유 ID 부여
- 타입 할당
- 신뢰도/확실성 레벨 설정 (초기값)
- 출처 정보 기록 (어느 문장/문단에서 왔는지)

---

### **3단계: 간선 생성 (Edge Creation)**

**인접 정점 분석**
- 텍스트 순서상 가까운 정점 쌍부터 검토
- 같은 문장/문단에서 나온 정점들 우선 분석
- 거리가 먼 정점 쌍은 후순위

**명시적 연결 파악**
- 텍스트에 나타난 연결어 식별 (because, therefore, enables 등)
- 연결어가 나타내는 관계 타입 분류
- 방향성 결정 (A→B인지 B→A인지)

**논리적 의존성 파악**
- A 없이 B가 성립 불가능한지 검사 (prerequisite)
- A가 B를 가능하게 하는지 검사 (enables)
- A가 B를 뒷받침하는지 검사 (supports)

**간선 타입 할당**
- enables: A가 B를 가능하게 함
- supports: A가 B를 뒷받침함
- motivates: A가 B를 필요로 함
- validates: A가 B를 검증함
- contradicts: A가 B와 모순됨
- leads_to: A가 B로 이어짐
- prerequisite: A가 B의 전제임

**관계 강도 평가**
- 강한 연결: 논리적 필연성 (A이면 반드시 B)
- 중간 연결: 높은 개연성 (A이면 보통 B)
- 약한 연결: 가능성만 있음 (A이면 때때로 B)

---

### **4단계: 구조 검증 (Structure Validation)**

**완전성 검사**
- 모든 문장의 의미가 정점으로 표현되었는지 확인
- 누락된 암묵적 전제가 없는지 점검
- 텍스트의 핵심 논지가 그래프에 반영되었는지 확인

**연결성 검사**
- 고립된 정점(간선 없음) 식별
- 시작점(incoming edge 없음)과 종착점(outgoing edge 없음) 파악
- 주요 concept 정점들이 서로 경로로 연결되어 있는지 확인

**일관성 검사**
- 순환 참조 탐지 및 해결
- 모순된 간선 쌍 식별 (A→B와 A→¬B 동시 존재)
- 중복 정점 식별 (같은 의미를 다르게 표현)

**층위 분석**
- 정점들을 논리적 층위로 그룹화
- 상위층(결론) → 중간층(논거) → 하위층(증거) 구조 확인
- 층위 간 연결이 적절한지 검증

---

### **5단계: 정제 (Refinement)**

**정점 통합**
- 중복되거나 유사한 정점 병합
- 너무 세분화된 정점 통합
- 통합 시 모든 incoming/outgoing edges 보존

**정점 분할**
- 너무 복잡한 정점을 여러 개로 분해
- 하나의 정점에 여러 주장이 섞여있으면 분리
- 분할 시 간선도 재분배

**간선 정리**
- 중복 경로 제거 (A→B→C 있는데 A→C도 있으면 A→C 제거)
- 약한 간선 중 불필요한 것 삭제
- 암묵적 간선 명시화 (transitivity로 유도되는 것들)

**메타데이터 보완**
- 각 정점의 신뢰도 재평가
- 증거가 있는 정점의 신뢰도 상향
- 불확실한 정점 표시

---

### **6단계: 품질 평가 (Quality Assessment)**

**커버리지 평가**
- 원본 thesis의 몇 %가 그래프에 표현되었는지
- 핵심 주장이 모두 포함되었는지
- 중요한 증거가 누락되지 않았는지

**논리 밀도 평가**
- 평균 간선 수 / 정점 수 비율
- 너무 희소하면 연결 부족
- 너무 밀집하면 불필요한 연결 많음

**추적 가능성 평가**
- 각 정점을 원본 텍스트로 역추적 가능한지
- 출처가 명확하지 않은 정점 식별
- 추론으로 추가된 정점 표시

**다음 단계 준비**
- 약한 부분 식별하여 iteration 목표 설정
- 개선이 필요한 영역 우선순위 결정
- 초기 그래프 완성 → Graph Iteration Phase로 전환

---

### **분해 품질 기준**

**좋은 분해의 특징**
- 각 정점이 하나의 검증 가능한 주장을 담음
- 정점 간 연결이 명확한 논리적 관계를 나타냄
- 원본 thesis의 의미가 손실 없이 보존됨
- 그래프 구조가 논증의 흐름을 반영함
- 증거와 주장이 명확히 구분됨

**피해야 할 함정**
- 과도한 분해로 맥락 손실
- 과소 분해로 복잡한 정점 생성
- 임의적 간선 생성 (텍스트 근거 없음)
- 암묵적 전제를 명시하지 않음
- 정점 타입 분류 오류

---

## Graph Iteration - 그래프 반복 개선 {#graph-iteration}

### **1단계: 분석 (Analysis)**

**논리적 결함 탐지**
- 각 간선의 논리적 연결성 검사
- 논리적 비약(logical leap) 식별
- 중간 단계 누락 여부 확인

**구조적 문제 탐지**
- 고립 노드(incoming/outgoing edge 없음) 식별
- 순환 참조(circular dependency) 탐지
- 불필요한 중복 간선 확인

**증거 충분성 검사**
- 각 주장(claim) 정점에 대한 증거(evidence) 정점 연결 여부
- 증거 없는 주장 식별
- 약한 증거 판별

**명제 명확성 검사**
- 모호한 표현 식별
- 과도하게 강한 주장(always, never 등) 탐지
- 측정 불가능한 개념 식별

---

### **2단계: 검증 (Verification)**

**문헌 대조**
- 각 사실 주장을 peer-reviewed literature와 비교
- 문헌에서 지지되는지 확인
- 과장되거나 왜곡된 인용 확인

**데이터 검증 가능성**
- 각 명제가 실제 데이터로 테스트 가능한지 판단
- 측정 가능한 변수로 표현되었는지 확인
- 검증 방법이 존재하는지 확인

**논리 법칙 적용**
- Transitivity 확인 (A→B, B→C이면 A→C 성립?)
- Contradiction 검사 (모순된 간선 쌍 존재?)
- Sufficiency 검사 (A만으로 B 충분? 다른 조건 필요?)

---

### **3단계: 수정 (Modification)**

**정점 추가**
- 논리적 비약 사이에 중간 정점 삽입
- 누락된 전제 조건 정점 추가
- 필요한 증거 정점 추가

**정점 수정**
- 모호한 명제를 구체적으로 재작성
- 과장된 주장을 적절한 수준으로 약화
- 측정 불가능한 개념을 측정 가능하게 변경

**정점 제거**
- 중복된 정점 통합 및 제거
- 그래프에 기여하지 않는 정점 삭제
- 검증 불가능한 정점 제거

**간선 추가**
- 고립 노드를 다른 정점과 연결
- 발견된 논리적 관계를 간선으로 추가
- 증거 정점을 주장 정점에 연결

**간선 수정**
- 잘못된 방향의 간선 뒤집기
- 간선 타입(enables, supports 등) 재분류
- 약한 간선을 더 강한 논리로 교체

**간선 제거**
- 논리적으로 타당하지 않은 연결 삭제
- 중복 경로 중 불필요한 간선 제거
- 순환 참조를 끊기 위한 간선 제거

---

### **4단계: 재검증 (Re-verification)**

**변경 영향 분석**
- 수정된 정점에 연결된 모든 간선이 여전히 유효한지 확인
- 간선 변경이 주변 정점에 미치는 영향 분석
- Cascading effect로 추가 수정이 필요한지 판단

**전체 일관성 검사**
- 수정 후 새로운 모순이 생기지 않았는지 확인
- 전체 경로들이 여전히 논리적인지 검증
- 순환 참조가 새로 생기지 않았는지 확인

**개선도 평가**
- 논리적 일관성 점수 계산 (이전 iteration과 비교)
- 증거 커버리지 비율 계산
- 약한 연결 개수 카운트

**종료 조건 판단**
- 더 이상 개선할 부분이 없으면 종료
- 개선도가 미미하면 종료
- 최대 iteration 도달 시 종료

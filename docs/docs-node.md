# 노드 문서

## 노드 리스트

| 노드 이름 | 노드 설명 |
|-----------|-----------|
| SMA | Sequence Moving Average 연산 노드 |
| ADD | 두 개의 value를 더하는 연산 노드 |
| SHIFT | Sequence data shift를 period 만큼 shift 연산 노드 |
| DIFF | (n)번째 행과 (n-period)번째 행과의 차이 연산 노드 |
| PctChange | (n)번째 행과 (n-period)번째 행과의 변화율 연산 노드 |
| SHIFTSIGN | 부호 shift 연산 노드 |
| ABS | 절댓값 연산 노드 |
| DIV | 두 값의 나눗셈 연산 노드 |
| SUB | 두 값의 a-b 계산 노드 |
| Comparison | 두 값 a, b에 대하여 a > b 여부 연산 노드 |
| NewHigh | New High 갱신 여부 연산 노드 |
| NewLow | New Low 갱신 여부 연산 노드 |
| ZScoreNorm | Seq 데이터를 정규화 (평균=0, 표준편차=1) 연산 노드 |
| QuantileRank | 각 데이터의 값을 백분위 값으로 바꾸는 연산 노드 |
| CORR | 시계열의 상관계수 노드 |
| STD | 표준편차 연산 노드 |
